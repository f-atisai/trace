# Guides

Task-oriented guidance for using TRACE in statistical-programming workflows.

Start here if you understand what TRACE is and want to use it in a program:

1. [Getting Started with TRACE](getting-started.md) — install TRACE, instrument a statistical workflow, read live events, and review a finalized provenance-backed log.
2. [TRACE Statistical Programming Examples](../../examples/README.md) — run the public CDISC Pilot Study flagship programs.
3. [TRACE Reviewer Examples](../examples/README.md) — interpret those programs from a reviewer perspective.
4. [Using TRACE with Quarto](quarto.md) — use TRACE inside Quarto while keeping TRACE independent of the authoring environment.

Reference material:

- [TRACE API](../api/README.md) — authoritative Developer Preview Python API.
- [TRACE Core Operations v0.1](../framework/core-operations-v0.1.md) — canonical TRACE operation meanings.
- [Reviewing Statistical Programs with TRACE](../framework/reviewer-guide.md) — reviewer workflow for TRACE execution evidence.

The design documents explain rationale and architecture history; they are not required to use TRACE.
